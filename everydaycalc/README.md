# EverydayCalc

A free, static, browser-based calculator website.

## Preview locally
Open `index.html` in a browser. Tool pages are under `tools/<slug>/`.

## Deploy
Hosted under the `everydaycalc/` directory of the GitHub Pages repository.

## Before advertising monetization
- Verify every formula and edge case.
- Replace the GitHub contact link with a monitored contact address or form.
- Review privacy/consent language against actual analytics and ad services.
- Add an appropriate consent management solution for applicable regions before personalized ads/cookies.
- Apply for AdSense only after the site has useful, original content and is fully functional.

No analytics or advertising scripts are installed by default.
