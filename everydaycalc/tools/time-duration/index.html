How to use this time duration calculator

Enter a start time and end time. If the end time is earlier than the start time, the calculator treats it as the following day.

Example calculation

From 9:00 AM to 5:30 PM is 8 hours and 30 minutes.

Frequently asked question

Can I calculate an overnight shift?

Yes. Enter the start and end times; an earlier end time is interpreted as occurring the next day.

Is this calculator free?

Yes. EverydayCalc tools are free to use, work in a modern browser and do not require registration.

Are my inputs saved?

The calculation runs in your browser. The values you enter are not intentionally sent to an EverydayCalc server.
