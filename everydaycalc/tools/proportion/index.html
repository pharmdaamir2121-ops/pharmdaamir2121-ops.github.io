How to use this proportion calculator

Enter the three known values in a proportion a:b = c:x. The calculator uses cross multiplication to solve for the missing fourth value.

Example calculation

If 2/3 = 4/x, cross multiplication gives 2x = 12, so x = 6.

What is a proportion?

A proportion is an equation stating that two ratios are equal.
