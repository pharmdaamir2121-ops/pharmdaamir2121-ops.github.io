How to use this gpa calculator

Add each course's credit value and grade points using the scale provided by your school. The calculator weights each grade by its course credits.

Example calculation

A 4.0 grade in a 3-credit course and a 3.0 grade in a 1-credit course produce a 3.75 GPA.

Frequently asked question

Does every school use the same GPA scale?

No. Institutions use different grading scales and rules. Enter the grade-point values specified by your institution.

Is this calculator free?

Yes. EverydayCalc tools are free to use, work in a modern browser and do not require registration.

Are my inputs saved?

The calculation runs in your browser. The values you enter are not intentionally sent to an EverydayCalc server.
